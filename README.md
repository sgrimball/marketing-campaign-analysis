# Marketing Campaign Performance Analysis

## Project Overview
This project analyzes marketing campaign performance data using Python, pandas, matplotlib, and seaborn.

The analysis explores campaign ROI, customer engagement, conversion rates, channel effectiveness, and customer segment performance.

## Tools Used
- Python
- pandas
- matplotlib
- seaborn

## Key Insights
- Social Media campaigns generated the highest ROI.
- Multi-channel campaigns outperformed single-channel strategies.
- Average campaign conversion rate was approximately 22%.
- Strong relationships were identified between clicks, conversions, and revenue.
- Customer segment analysis revealed opportunities for targeted marketing optimization.

## Skills Demonstrated
- Data cleaning
- Exploratory data analysis (EDA)
- Data visualization
- Business insight generation
- Marketing performance analysis
